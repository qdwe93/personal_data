STEP 1. Flow 영상 15개를 하나로 연결하기

1-1. 새 프로젝트 만들기

  • DaVinci Resolve를 실행하고 Project Manager에서 New Project를 누릅니다.

  • 프로젝트 이름을 예: VOCA_2026_08_10으로 지정합니다.

  • 아래쪽 페이지 탭에서 Edit를 선택합니다. 처음에는 Cut보다 Edit 페이지가 이해하기 쉽습니다.

File > Project Settings > Master Settings — 가로 1920×1080 또는 세로 1080×1920, 30fps를 확인

1-2. 15개 영상을 Media Pool에 가져오기

  • Windows 탐색기에서 15개 MP4를 모두 선택해 왼쪽 위 Media Pool로 끌어놓습니다.

  • Media Pool을 List View로 바꾸고 Clip Name 열을 클릭해 01→15 오름차순으로 정렬합니다.

  • 첫 번째와 마지막 파일명을 확인합니다. 정렬이 틀리면 타임라인에서도 순서가 틀어집니다.

미디어 오프라인 파일을 가져온 뒤 원본 폴더를 이동하거나 이름을 다시 바꾸면 Media Offline이 될 수 있습니다. 프로젝트를 끝낼 때까지 01_source 폴더를 그대로 유지하세요.



1-3. 순서대로 타임라인 만들기

  • Media Pool에서 01번을 클릭하고 Shift를 누른 채 15번을 클릭해 모두 선택합니다.

  • 선택한 클립을 아래 타임라인의 V1/A1 시작점으로 한 번에 끌어놓습니다.

  • 타임라인 확대·축소 슬라이더로 전체를 보고, 15개 클립 사이에 빈 공간이 없는지 확인합니다.

Timeline > Delete Gaps — 빈 공간이 생겼을 때만 사용. 메뉴 이름은 버전에 따라 Edit 메뉴 아래에 보일 수 있습니다.

  • 처음부터 끝까지 재생해 순서, 화면 비율, 음량, 잘림을 확인합니다.

완료 기준 타임라인 길이가 약 2분이고, 01번부터 15번까지 끊김 없이 이어져 있으면 STEP 1 완료입니다.

STEP 3. Gemini에서 정확한 SRT 만들기

3-1. 동영상 업로드

  • gemini.google.com을 열고 새 대화를 시작합니다.

  • +(Add files) > Upload files에서 STEP 2의 MP4를 첨부합니다.

  • 아래 프롬프트를 그대로 붙여넣습니다.

첨부한 동영상의 영어 음성을 분석해서 UTF-8 SRT 자막을 만들어줘.

조건:
1) 영상은 8초짜리 영어 단어 학습 영상 15개를 연결한 것이다.
2) 각 8초 구간마다 자막을 정확히 2개 만든다. 첫 자막은 영어 단어 1개, 두 번째 자막은 그 단어의 영어 예문이다.
3) 전체 SRT 항목은 정확히 30개여야 한다. 홀수 번호는 단어, 짝수 번호는 예문이다.
4) 음성에서 실제로 말한 영어를 그대로 적고, 철자·대소문자·문장부호를 교정한다.
5) 한국어 번역, WORD:, EXAMPLE: 같은 라벨, 설명문은 넣지 않는다.
6) 단어를 반복 발음해도 단어 자막은 한 번만 표시한다.
7) 자막이 음성과 자연스럽게 맞도록 시작·종료 시간을 정하고 서로 겹치지 않게 한다.
8) 마크다운 코드블록이나 설명 없이, 유효한 SRT 본문만 출력한다. 시간 형식은 00:00:00,000 --> 00:00:00,000을 사용한다.



3-2. Gemini 결과 검수

  • 번호가 1부터 30까지 빠짐없이 있는지 확인합니다.

  • 홀수 번호가 짧은 단어, 짝수 번호가 완전한 예문인지 확인합니다.

  • 같은 단어가 두 번 나오거나 예문이 둘로 쪼개졌다면 Gemini에 번호를 지정해 수정시킵니다.

  • 긴 예문은 의미가 끊기지 않는 위치에서 최대 2줄이 되도록 줄바꿈할 수 있습니다.

검수 요청 예시 — ‘7번은 단어, 8번은 예문이 되도록 수정하고 전체 30개 SRT만 다시 출력해줘.’

3-3. SRT 파일로 저장

  • Gemini 결과의 SRT 본문 전체를 복사합니다.

  • Windows 메모장을 열어 붙여넣습니다.

파일 > 다른 이름으로 저장 — 파일명 VOCA_2026_08_10.srt / 파일 형식 모든 파일 / 인코딩 UTF-8

  • 03_subtitle 폴더에 저장합니다. 실제 이름이 .srt.txt가 되지 않았는지 확인합니다.

SRT 예시 1번은 단어, 2번은 예문입니다. SRT 자체에는 글꼴·색상 같은 스타일이 저장되지 않으며, 스타일은 리졸브에서 적용합니다.



1 | 00:00:00,300 --> 00:00:01,800 | abandon
2 | 00:00:02,200 --> 00:00:07,300 | The crew had to abandon the damaged ship.

STEP 4. SRT를 DaVinci Resolve로 가져오기

  • Edit 페이지로 돌아가 타임라인 재생 헤드를 맨 처음으로 이동합니다.

File > Import > Subtitle — 03_subtitle의 .srt 파일 선택

  • SRT가 Media Pool에 들어오면 타임라인의 영상 트랙 위쪽으로 끌어놓습니다.

  • 새 Subtitle Track이 생기고 약 30개의 자막 블록이 표시되는지 확인합니다.

  • 재생하면서 자막이 음성보다 빠르거나 늦으면 해당 자막 블록의 양 끝을 드래그해 길이를 조정합니다.

Sample이 추가될 때 Effects Library > Titles > Subtitle을 끌어놓은 것입니다. 이것은 새 샘플 자막을 만드는 기능입니다. Sample 블록은 삭제하고, 반드시 File > Import > Subtitle로 SRT를 가져오세요.



STEP 5. 단어와 예문에 서로 다른 스타일 적용하기

5-1. Subtitle Region을 2개 만들기

  • Subtitle Track의 빈 공간 또는 트랙 헤더를 마우스 오른쪽 버튼으로 클릭합니다.

Add Subtitle Region — 기존 Region 아래나 위에 두 번째 자막 영역이 생깁니다.

  • 기존 Region 1은 예문용으로 사용하고, 새 Region 2는 단어용으로 사용합니다.

  • 홀수 번호에 해당하는 짧은 단어 자막들을 Ctrl+클릭으로 선택합니다.

  • 선택한 단어 자막을 세로 방향으로 Region 2에 끌어놓습니다. 한꺼번에 이동이 잘 안 되면 15개만 하나씩 옮겨도 됩니다.

  • 예문 자막은 Region 1에 그대로 둡니다. 시간 위치는 바꾸지 말고 위·아래 Region만 변경합니다.

구분이 쉬운 이유 Gemini 프롬프트에서 홀수 번호를 단어, 짝수 번호를 예문으로 고정했기 때문에 타임라인에서도 짧은 블록과 긴 블록을 빠르게 구분할 수 있습니다.



5-2. 단어 Region 스타일

  • Track 탭에서 지정한 값은 그 Region의 모든 단어 자막에 적용됩니다.

STEP 6. 자막 타이밍과 화면 최종 검수

전체 재생 검수 체크리스트

  • □ 각 8초 구간에 단어 자막 1개와 예문 자막 1개가 모두 있다.

  • □ 단어는 큰 글씨, 예문은 작은 글씨로 일관되게 보인다.

  • □ 흰 배경이 글자보다 충분히 크고, 배경 투명도가 너무 낮지 않다.

  • □ 예문이 세 줄 이상 되거나 화면 밖으로 잘리지 않는다.

  • □ 자막이 다음 8초 영상으로 넘어가 남아 있지 않는다.

  • □ 철자, 대소문자, 마침표·물음표가 맞다.

  • □ 영상과 자막이 같은 내용을 말한다.

  • □ 첫 프레임과 마지막 프레임에 불필요한 검은 화면이 없다.

자막 위치가 겹칠 때

  • 단어와 예문이 시간상 겹치지 않는다면 두 Region의 위치를 같게 두어도 됩니다.

  • 둘이 동시에 보이는 구간이 있다면 단어는 화면 중앙 또는 상단, 예문은 하단으로 Position Y를 나눕니다.

  • Region 스타일을 바꾸면 해당 종류의 15개 자막이 한꺼번에 이동하므로, 개별 자막을 하나씩 움직일 필요가 없습니다.

다음 프로젝트를 위한 스타일 저장

  • Inspector의 점 3개 메뉴에서 Track Style Preset 저장 기능을 찾습니다.

  • 단어 스타일은 VOCA_WORD_WHITE, 예문 스타일은 VOCA_SENTENCE_WHITE처럼 저장합니다.

  • 다음 영상부터는 Region 2개를 만든 뒤 저장한 프리셋을 불러오면 됩니다.

STEP 8. YouTube에 업로드하기

  • studio.youtube.com에 접속합니다.

만들기(Create) > 동영상 업로드(Upload videos)

  • 04_final의 FINAL MP4를 선택합니다.

  • 제목, 설명, 썸네일, 재생목록을 입력합니다.

  • 아동용 콘텐츠 여부는 실제 대상과 내용에 맞게 선택합니다.

  • Checks 단계에서 저작권 검사를 기다립니다.

  • 처음에는 Visibility를 Unlisted(미등록)로 두고 저장합니다.

  • PC와 휴대폰에서 미등록 영상을 끝까지 재생해 자막 크기, 음량, 화면 잘림을 확인합니다.

  • 문제가 없으면 Public(공개) 또는 Schedule(예약)로 변경합니다.

권장 업로드 습관 최종 파일을 바로 공개하지 말고 미등록으로 한 번 검수하세요. 특히 모바일에서는 예문이 작거나 화면 가장자리와 가까운 문제가 더 잘 보입니다.
