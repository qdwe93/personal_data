# 다빈치 리졸브로 단어 영상 만들기 — 전체 매뉴얼

> Google Flow 8초 영상 15개 → 하나로 합치기 → 자막 생성 → 단어/예문 스타일 분리 → 유튜브 업로드

---

## 0. 시작 전에

### 무료판이면 충분합니다

DaVinci Resolve 무료판은 **렌더링 워터마크가 없습니다.** CapCut처럼 로고가 박히지 않습니다.
단, Studio 전용 기능(일부 Resolve FX, 노이즈 리덕션, 페이스 리파인먼트 등)을 쓰면 그때만 렌더 결과에 워터마크가 생깁니다. 이 작업에는 그런 기능을 안 쓰니 신경 안 쓰셔도 됩니다.

### CapCut ↔ 리졸브 용어 대응표

| CapCut | 다빈치 리졸브 |
|---|---|
| 미디어 추가 | Media Pool (Media 페이지) |
| 편집 화면 | Edit 페이지 |
| 내보내기 | Deliver 페이지 |
| 자동 자막 | (없음 → 제미나이 사용) |
| 텍스트 스타일 | Inspector 패널 (우측 상단) |

리졸브는 화면 **맨 아래에 페이지 전환 아이콘 7개**가 있습니다. 우리가 쓸 건 `Media`, `Edit`, `Deliver` 세 개뿐입니다. 나머지(Cut, Fusion, Color, Fairlight)는 무시하세요.

### 미리 해둘 것 ⚠️

**영상 파일 15개를 순서대로 리네임하세요.** `01_word.mp4`, `02_word.mp4` … `15_word.mp4`
리졸브는 이름순 정렬로 한 번에 붙이는 게 제일 빠른데, 파일명이 뒤죽박죽이면 순서가 꼬입니다. 여기서 5분 쓰면 뒤에서 30분 아낍니다.

## 1. 프로젝트 만들기 + 영상 15개 합치기

### 1-1. 프로젝트 생성

1. 리졸브 실행 → Project Manager 창에서 **New Project**
2. 이름 입력 (예: `Vocab_20260810`) → Create

### 1-2. 프로젝트 설정 (클립 넣기 전에 먼저!)

우측 하단 **톱니바퀴 아이콘** → Project Settings → Master Settings

- **Timeline Resolution**: 원본 영상에 맞춥니다.
  - 가로 영상 → `1920 x 1080 HD`
  - 세로(쇼츠용) 영상 → 드롭다운에서 `Custom` 선택 후 `1080 x 1920` 입력
- **Timeline Frame Rate**: 원본과 동일하게. Veo/Flow 결과물은 보통 **24fps**입니다. 모르면 일단 두고, 1-3 단계에서 리졸브가 물어보는 대로 하세요.

> ⚠️ **프레임레이트는 타임라인에 클립을 하나라도 올리는 순간 잠깁니다.** 나중에 못 바꿉니다. 지금 정하세요.

### 1-3. 영상 불러오기

1. 하단 아이콘에서 **Media** 페이지 클릭
2. 좌측 상단 `Media Storage`에서 영상이 있는 폴더 찾기 → 파일 15개 전체 선택 → 아래쪽 **Media Pool** 영역으로 드래그
   (또는 Edit 페이지에서 `Ctrl + I` 로 파일 선택)
3. "프레임레이트가 다른데 프로젝트 설정을 바꿀까요?" 팝업이 뜨면 → **Change** 클릭

### 1-4. 한 번에 이어붙이기

1. Media Pool을 **리스트 뷰**로 바꾸고 (우측 상단 아이콘), `Clip Name` 헤더를 클릭해 **이름순 정렬**
2. 15개 전체 선택 (`Ctrl + A`)
3. 우클릭 → **Create New Timeline Using Selected Clips**
4. 타임라인 이름 입력 → Create

이러면 15개가 순서대로, 빈틈 없이 하나로 붙은 타임라인이 만들어집니다.

### 1-5. 확인

**Edit** 페이지로 이동해서:
- 클립 사이에 검은 틈이 없는지 (있으면 그 클립 우클릭 → 삭제 대신, 클립 드래그해서 붙이거나 틈 우클릭 → `Delete`)
- 타임라인 총 길이가 **약 2분 (8초 × 15 = 120초)** 인지
- 재생(`Space`)해서 순서 맞는지

순서가 틀렸으면 해당 클립을 드래그해서 옮기면 됩니다.

## 2. 1차 Export (자막 생성용)

1. 하단 **Deliver** 페이지 클릭
2. 좌측 상단 프리셋에서 **H.264 Master** 또는 **YouTube** 클릭
3. `Filename`에 파일명, `Location`의 Browse로 저장 위치 지정
4. Video 탭에서 Format `MP4`, Codec `H.264` 확인
5. 좌측 하단 **Add to Render Queue** → 우측 렌더 큐에서 **Render All**

> 💡 이 파일은 제미나이한테 보여줄 용도라 화질이 중요하지 않습니다. 업로드가 느리면 Video 탭에서 Resolution을 `1280x720`으로 낮추고 `Quality`를 Automatic 대신 낮은 비트레이트로 잡으면 파일이 훨씬 가벼워집니다.

## 3. 제미나이로 자막(SRT) 만들기

렌더된 mp4를 제미나이에 업로드하고, 아래처럼 요청하세요.

### 프롬프트 예시

```
첨부한 영상의 자막을 SRT 형식으로 만들어줘.

이 영상은 8초짜리 클립 15개를 이어붙인 것이고,
각 클립마다 [영어 단어] → [영어 예문] 순서로 나옵니다.

다음 두 개의 SRT를 각각 따로 출력해줘:

【파일 1: words.srt】 — 단어만
【파일 2: sentences.srt】 — 예문만

규칙:
- 각 파일 안에서 자막 번호는 1부터 다시 순서대로 매길 것
- 타임코드는 00:00:00,000 형식으로 정확하게
- 실제 발화 시작/끝 시점에 맞출 것
- SRT 텍스트 외에 설명, 주석, 코드블록 표시는 넣지 말 것
```

### 핵심: SRT를 두 개로 나누는 이유

리졸브에서 **자막 스타일은 트랙 단위로 적용**됩니다. 자막 하나하나에 다른 스타일을 주는 건 번거롭고 실수가 많습니다.
→ **단어 트랙 / 예문 트랙을 따로 만들면**, 트랙마다 스타일을 한 번씩만 설정하면 끝납니다. 이게 제일 깔끔합니다.

### 타임코드 검수 (중요)

제미나이가 준 타임코드는 몇백 ms씩 어긋나는 경우가 흔합니다. 클립이 정확히 8초씩이라는 걸 이용해 눈으로 검산하세요.

| 클립 | 시작 | 끝 |
|---|---|---|
| 1 | 00:00:00 | 00:00:08 |
| 2 | 00:00:08 | 00:00:16 |
| 3 | 00:00:16 | 00:00:24 |
| … | … | … |
| 15 | 00:01:52 | 00:02:00 |

n번째 클립의 단어 자막은 `(n-1)×8초` 근처에서, 예문 자막은 그 뒤에서 시작해야 정상입니다. 크게 벗어난 게 있으면 그 줄만 손으로 고치세요.

### 저장

메모장에 붙여넣고 **`words.srt`**, **`sentences.srt`** 로 각각 저장합니다.
⚠️ 저장할 때 **인코딩을 `UTF-8`** 로 지정하세요 (메모장: 저장 창 하단 인코딩 드롭다운). ANSI로 저장하면 한글이 깨집니다.

## 4. 자막 가져오기 + 스타일 두 가지 적용

### 4-1. 자막 트랙 2개 만들기

**Edit** 페이지에서:

1. 상단 메뉴 `File` → `Import` → `Subtitle…` → **words.srt** 선택
   → 타임라인 위쪽에 `Subtitle 1` 트랙이 생기고 자막이 깔립니다
2. 한 번 더 `File` → `Import` → `Subtitle…` → **sentences.srt** 선택
   → `Subtitle 2` 트랙이 추가로 생깁니다

타임라인 왼쪽 트랙 헤더에 `Subtitle 1`, `Subtitle 2`가 보이면 성공입니다.

### 4-2. 단어 스타일 (Subtitle 1)

1. `Subtitle 1` 트랙의 자막 클립 **아무거나 하나 클릭**
2. 우측 상단 **Inspector** 버튼 클릭 → `Caption` 탭
3. 아래 값들을 조정 (이 설정은 해당 트랙 전체에 적용됩니다)

| 항목 | 추천값 |
|---|---|
| Font Family | 영어만이면 `Montserrat` / `Poppins`, 한글 섞이면 `Pretendard` 또는 `나눔스퀘어` |
| Font Face | Bold |
| Size | 90~120 (세로영상) / 70~90 (가로영상) |
| Color | 흰색 또는 노란색 (`#FFE066`) |
| Stroke (외곽선) | 검정, 두께 6~10 |
| Drop Shadow | 켜기 (가독성 확 올라감) |
| Position Y | 화면 **위쪽 1/3** 지점으로 |

### 4-3. 예문 스타일 (Subtitle 2)

`Subtitle 2` 트랙의 자막 클립 하나 클릭 → Inspector에서:

| 항목 | 추천값 |
|---|---|
| Font Face | Regular 또는 Medium |
| Size | 단어의 **절반~60%** 정도 |
| Color | 흰색 |
| Background | 켜기, 검정 + Opacity 50~60% |
| Position Y | 화면 **아래쪽 1/4** 지점으로 |

### 4-4. 확인

타임라인을 처음부터 재생하면서:
- 단어와 예문이 **세로로 겹치지 않는지**
- 예문이 길어서 화면 밖으로 나가지 않는지 (나가면 Size를 줄이거나, 자막 클립을 더블클릭해서 텍스트 중간에 줄바꿈 넣기)
- 타이밍이 영상 속 발화와 맞는지 — 안 맞으면 자막 클립 **끝을 드래그**해서 길이 조절, 통째로 드래그해서 위치 이동

## 5. 최종 Export (⚠️ 여기가 제일 실수 많은 곳)

**Deliver** 페이지로 이동.

### 5-1. 자막을 영상에 굽기 (필수!)

1. 좌측 설정 패널에서 **`Subtitle Settings`** 탭 클릭
2. **`Export Subtitle`** 체크박스 켜기
3. Format 드롭다운을 **`Burn into video`** 로 선택
4. 자막 트랙이 2개이므로, **Subtitle 1과 Subtitle 2 둘 다** 굽도록 선택되어 있는지 확인
   (트랙 선택 드롭다운이 있으면 하나씩 추가)

> 🚨 이걸 안 하면 **자막이 하나도 안 보이는 영상**이 나옵니다. 리졸브 초보가 가장 많이 겪는 문제입니다.

### 5-2. 화질 설정

- 프리셋: **YouTube 1080p** (또는 세로영상이면 H.264 Master + 해상도 1080x1920)
- Format: `MP4`, Codec: `H.264`
- Quality: `Automatic` (Best)

### 5-3. 렌더

파일명/저장위치 지정 → **Add to Render Queue** → **Render All**

렌더 끝나면 **반드시 파일을 열어서 자막이 나오는지 눈으로 확인**하세요.

## 6. 유튜브 업로드

### 방법 A. 리졸브에서 바로 올리기

1. 상단 메뉴 `DaVinci Resolve` → `Preferences` → `System` → `Internet Accounts` → YouTube 계정 로그인
2. Deliver 페이지에서 프리셋 **YouTube** 선택
3. 렌더 설정 하단의 **`Upload directly to YouTube`** 체크
4. 제목, 설명 입력 → 렌더

### 방법 B. 수동 업로드 (권장)

썸네일, 재생목록, 최종화면 등 세밀한 설정이 가능해서 이쪽을 추천합니다.

1. [studio.youtube.com](https://studio.youtube.com) → 만들기 → 동영상 업로드
2. 제목 예시: `초등 영어단어 15개 | 예문으로 한 번에 외우기 #1`
3. 설명에 이번 영상에 나온 단어 15개 목록을 텍스트로 넣기 (검색 노출에 도움됩니다)
4. **⚠️ '아동용' 설정**: 어린이 학습 콘텐츠라면 "예, 아동용입니다"를 선택해야 정책 위반을 피합니다. 대신 댓글·맞춤광고·저장 기능이 꺼집니다.
5. 세로 영상 + 3분 이하면 **자동으로 쇼츠로 분류**됩니다 (2분짜리니 해당됨)

### 보너스: SRT를 CC 자막으로도 올리기

영상에 자막을 구웠더라도, 유튜브 스튜디오의 `자막` 메뉴에서 `sentences.srt`를 별도로 업로드해두면 유튜브가 내용을 텍스트로 인식해서 검색 노출에 유리합니다. 30초면 됩니다.

## 7. 자주 막히는 지점

| 증상 | 원인 / 해결 |
|---|---|
| 렌더 결과에 워터마크 | Studio 전용 이펙트를 썼을 때만 발생. 적용한 Resolve FX를 제거하세요 |
| 자막이 안 보임 | Deliver에서 `Burn into video` 안 켬 (5-1번) |
| 한글 자막이 □□□ 로 깨짐 | 한글 미지원 폰트. Pretendard, 나눔스퀘어, 에스코어드림 등으로 변경 |
| SRT 가져왔는데 글자 깨짐 | .srt 파일이 ANSI 인코딩. UTF-8로 다시 저장 |
| 프레임레이트를 못 바꿈 | 타임라인에 클립이 올라간 뒤엔 잠김. 새 프로젝트를 만들어 처음부터 |
| 클립 순서가 뒤죽박죽 | 파일명을 01~15로 리네임 후 Media Pool 이름순 정렬해서 다시 |
| 재생이 뚝뚝 끊김 | 우측 하단 재생 해상도를 `Half` 또는 `Quarter`로. 렌더 화질과 무관합니다 |

## 8. 다음 회차부터는 (시간 단축)

1편 세팅이 끝나면 **Project Manager에서 프로젝트 우클릭 → Duplicate** 하세요.
복제한 프로젝트에서 타임라인의 영상 클립만 새것으로 교체하면, 자막 스타일 설정을 다시 할 필요가 없습니다.

더 나아가려면 자막 트랙 스타일을 정한 뒤 **Edit → 자막 클립 우클릭 → Save as Default** 로 기본값 저장도 가능합니다.
